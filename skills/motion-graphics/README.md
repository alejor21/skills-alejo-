# Motion Graphics

Skills for building high-end commercial motion graphics (SaaS, app, product and brand ads) as code, rendered to 4K video, with Blender for photoreal product shots. Kept apart from the code and workflow skills on purpose: this bucket is the base for our own motion graphics skill. Like `in-progress/`, it's excluded from the plugin and the top-level README, and its skills get no docs pages.

See [GUIA.md](./GUIA.md) for a Spanish walkthrough of how to use it and what each ad needs.

- **[saas-animation](./saas-animation/SKILL.md)**: Make short (8 to 20s), high-end SaaS, app, product and brand animations as code: numbered storyboard first, one continuous camera, shots that morph into each other, real UI in 3D, puppet-animated illustrations, Blender product shots, sound design and music prompts. Third-party reference skill, vendored as the starting point for our own.
